# מיון במזנון

משחק של פריזמה (רשת אמית) לכיתה ז, סטטיסטיקה: ארגון נתונים.
מנהלת המזנון צריכה לסדר על מגשים מאכלים שהתלמידים הציעו בסקר.

- שלב 1 – מיון לפי הוראה: למגשים יש שמות, גוררים כל מאכל למקומו.
- שלב 2 – מה הכלל? המאכלים כבר ממוינים בלי שמות; מגלים לפי מה מיינו, ומשלימים.
- שלב 3 – ממיינים לבד: נותנים שמות למגשים, ממיינים, והמנהלת בודקת קריטריון ברור, קבוצות זרות וקבוצות ממצות.

כל הנכסים מוטמעים בתוך `index.html`: פונט Simpler Pro, לוגו, אייקונים וצלילים מתיקיית prisma, ואיורי מאכלים מקוריים.

## פרסום ב־GitHub Pages
1. מעלים את `index.html` לשורש המאגר.
2. Settings → Pages → Branch: `main`, תיקייה `/ (root)` → Save.
